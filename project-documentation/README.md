**Version:** 1.0

**Audience:** Founders, Investors, Operations Teams, Therapists, Support Staff, Future Stakeholders

## About This Document

This documentation system provides a complete business-level overview of the Sukoon AI platform — what it does, how it works for each type of user, how money flows, how safety is maintained, and where the platform is headed.

This is **not** a technical manual. It is written for people who need to understand, operate, fund, or grow Sukoon AI — without needing to understand the code behind it.

## Quick Facts

| Item | Detail |
|---|---|
| **Platform Name** | Sukoon AI |
| **Product Type** | AI-powered mental health and therapy platform |
| **Primary Users** | Clients seeking emotional support, Licensed therapists, Platform administrators |
| **AI Engine** | Google Gemini (large language model) |
| **Languages Supported** | English, Urdu, Roman Urdu, Sindhi, Pashto, Siraiki, Arabic, Spanish |
| **Markets Targeted** | South Asia (Pakistan, India), MENA, Global diaspora |
| **Core Business Model** | Subscription + Therapist Session Commission (15%) |
| **Crisis Support** | Built-in 24/7 AI crisis detection with human escalation |
