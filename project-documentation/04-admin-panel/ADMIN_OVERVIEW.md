## Executive Summary

The Sukoon AI Admin Panel is a comprehensive management dashboard that gives authorized staff control over every dimension of the platform — users, therapists, finances, support, content, safety, and analytics. The admin panel is the operational nerve center of the platform, enabling a small team to govern a platform serving thousands of users.

---

## Purpose

To provide an overview of the Admin Panel — its scope, structure, key responsibilities, and the roles of those who use it.

---

## Stakeholders

- Platform admins (primary operators)
- Finance team (revenue and payouts)
- Support team (ticket resolution)
- Clinical team (safety oversight)
- Executive team (governance)

---

## 1. What the Admin Panel Is

The Admin Panel is an internal-only dashboard accessible to accounts with `isAdmin = true` or `role = "staff"`. It is not visible to regular clients or therapists.

After logging in, admin users are automatically directed to the **Admin Dashboard** rather than the standard client interface. The dashboard provides a full-spectrum view of platform activity and tools for action on any dimension.

---

## 2. Admin Roles and Access Levels

The platform supports a **Team Members** system that allows different levels of admin access:

| Role | Access Level |
|---|---|
| **Super Admin** | Full access to all platform functions |
| **Accountant** | Finance module access only |
| **Moderator** | User management and support |
| **Viewer** | Read-only access to dashboards |
| **Team Member** | Custom configurable access |

### Access Expiry
Team member access can have an **expiry date** set. After expiry, the account becomes inactive automatically. This is important for contractors or temporary staff.

### Permission Dimensions
Each team member's permissions are configured across:
- **Users** — Full, Read, or None
- **Therapists** — Full, Read, or None
- **Finance** — Full, Read, or None
- **Chat** — Full, Read, or None
- **System** — Full, Read, None, or Locked

## 3. Admin Dashboard Sections

The Admin Dashboard is organized into distinct sections, each accessible from the main navigation:

### 3.1 Main Dashboard (`admin-dashboard`)
The landing view when an admin logs in. Displays:
- Platform health metrics (user counts, session counts, active therapists)
- Today's pending actions (unreviewed applications, unverified payments, open tickets)
- Recent risk alerts
- Recent system notifications

### 3.2 Users (`admin-users`)
- View all registered clients
- Filter users by status (active, suspended, pending, banned)
- Search users by name, email, or ID
- View user profiles including risk level, last active date
- Suspend, unsuspend, or ban accounts
- View user session and journal history (for clinical review)

### 3.3 Therapist Applications (`admin-therapists`)
- View all therapist applications (pending, approved, rejected)
- Review submitted credentials (CV, degree, license number)
- Approve or reject applications
- Add notes to applications

### 3.4 Connections (`admin-connections`)
- View all therapist-client connections
- See connection status (Active, Disputed, Ended)
- Manually create or end connections
- Resolve disputed connections

### 3.5 Finance (`admin-finance`)
- Revenue tracking (session payments, subscription payments)
- Payout requests from therapists (approve or reject)
- Marketing expense tracking
- Commission management
- Financial reporting

### 3.6 Support (`admin-support`)
- View all open support tickets
- Filter by category, priority, status
- Reply to tickets and update status
- Resolve or close tickets
- Escalate to senior team members

### 3.7 Broadcast (`admin-broadcast`)
- Send platform-wide messages to all users, therapists, or clients
- Schedule broadcasts or send immediately
- View broadcast history

### 3.8 Subscriptions (`admin-subscriptions`)
- View all active user subscriptions
- Manually activate or adjust subscriptions
- Create, edit, or deactivate subscription plans

### 3.9 Risk Alerts (`admin-alerts`)
- View all crisis risk alerts generated by AI monitoring
- Assign crisis-certified therapists to at-risk clients
- Track alert resolution
- View safety incidents logged by therapists

### 3.10 Messages (`admin-messages`)
- View platform-wide direct message activity
- Monitor communications for policy compliance
- Access message threads if required for dispute resolution

### 3.11 Team Management (`admin-team`)
- Add new team members (admin staff)
- Configure access permissions per team member
- Set access expiry dates
- Suspend or remove team members

## 6. Admin Authentication

Admin accounts are authenticated through the same login system as all other users. Admin status is determined by:
- `isAdmin = true` flag on the user record
- `role = "admin"` or `role = "staff"` on the user record

Admin credentials are stored securely. There is an **initial default admin account** built into the platform (`admin@sukoon.ai` / `admin123`). **The default password must be changed immediately in production.**

## Business Impact

The Admin Panel enables a small operations team to:
- Scale platform governance without proportional headcount growth
- Maintain clinical safety through centralized alert monitoring
- Drive revenue through timely payment verification and subscription management
- Build therapist trust through fast, transparent payout processing
- Protect brand reputation through rapid response to support issues

---

## Risks

| Risk | Description | Mitigation |
|---|---|---|
| **Admin credential compromise** | Unauthorized admin access | Strong passwords; 2FA implementation |
| **Single admin bottleneck** | One admin responsible for all functions | Team member roles; task delegation |
| **Missed risk alerts** | Critical alert not actioned | Real-time alert notifications; on-call coverage |
| **Default credentials not changed** | Security vulnerability in production | Force password change on first admin login |
| **Over-privileged team members** | Staff seeing data they don't need to | Role-based access control strictly enforced |

---

## Recommendations

1. **Implement two-factor authentication (2FA)** for all admin accounts as a mandatory security control.
2. **Force password change** on the default admin account (`admin@sukoon.ai`) immediately during production deployment.
3. **Create a daily admin checklist** — a documented list of actions that must be completed each day, with time targets.
4. **Set up admin alert notifications** via email or SMS for critical events (new risk alert, high-priority ticket opened, application submitted).
5. **Implement admin audit logging** — record every significant admin action (approval, suspension, payout processing) with timestamp and admin ID for governance and accountability.
